# Mega Portfolio

Arabic/English portfolio source bundle. Download `Mega-Portfolio-Source.zip` from this repository and extract it to work with the full project. The bundle includes the latest Behance project embedding and visual identity carousel changes.

The current app uses Cloudflare Workers, D1, and R2. Deploy from the repository through Cloudflare Workers Builds after configuring those bindings and the server-side admin secrets. Do not expose admin secrets in source control.
